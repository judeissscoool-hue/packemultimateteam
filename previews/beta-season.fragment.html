How season rankings work
  • Only 82–0 Classic Drafts can be saved to rankings. Pack Mode is ineligible.
  • Each separate perfect draft earns 1,000 points. Your best OVR with Chem is added once, using the same uncapped rating as the court.
  • Reaching 82–0 does not lock your lineup. Keep rearranging, then choose Save 82–0 to Rankings.
  • Already saved? Update Best OVR improves that same entry. It still counts as one perfect draft.
  • One more perfect draft always ranks higher. Identical scores share a rank and its reward.
  • There is no daily limit on Classic Draft attempts.
